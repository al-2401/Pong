# Pong

Вертикальный Pong на Flutter: ракетки на коротких сторонах экрана, мяч
отскакивает от них и от боковых стен.

Сейчас реализована игра против компьютера. Сетевая игра (Wi-Fi, затем
Bluetooth) — следующий этап; решения по ней зафиксированы в
[docs/design.md](docs/design.md).

## Что есть

- физический движок на чистом Dart с фиксированным шагом 120 Гц и swept
  collision, покрытый тестами без эмулятора
- четыре уровня сложности: меняются и скорость мяча, и модель соперника
- настраиваемая инертность ракетки, влияющая и на управление, и на подкрутку
  мяча
- портрет и ландшафт — одно и то же поле, повёрнутое при отрисовке
- спидометр разгона мяча, счётчик серии и локальные рекорды
- ретро-оформление, звуки трёх тонов оригинального автомата, вибрация


## Структура

```
lib/engine/    симуляция, ИИ, правила — чистый Dart, без Flutter
lib/input/     управление пальцем
lib/ui/        отрисовка, проекция поля на экран, экраны
lib/settings/  локальные настройки игрока
lib/stats/     рекорды
lib/audio/     звук
test/engine/   физика, ИИ, ход матча (headless)
test/ui/       проекция поля и сквозной сценарий по экранам
```

Ключевое разделение: `GameRules` описывает физику матча и должен совпадать у
обоих игроков, `Preferences` — локальные предпочтения, которые на симуляцию не
влияют. Подробности и обоснования — в [docs/design.md](docs/design.md).
